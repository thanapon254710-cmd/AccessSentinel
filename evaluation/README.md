# AccessSentinel evaluation (Deliverable 4)

Experimental evaluation of the **Revised v3** architecture. Plan, gaps and roadmap: `docs/V3_AUDIT.md`.

Status: **Phases 1–2 done** (audit; event pipeline). No v3 experiment has been run yet; Phase 2 recorded
only verification measurements (`docs/PROGRESS.md`). The results in `experiments/results/` are
from the earlier D3 implementation and are kept as baselines.

Rules for everything in this folder:
- every figure and table is generated by a script from files in `results/raw/`; no value is typed by hand;
- every run stores `env_info.collect()` output, the git commit, seeds, parameters, and start and finish times;
- published numbers from other papers are kept apart, labelled "Reported by Reference Paper", with a page
  citation (`references/REFERENCES.md`);
- anything not measured is written as Not Reported, Not Comparable or Not Reproduced.

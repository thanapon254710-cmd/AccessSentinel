# AccessSentinel evaluation (Deliverable 4)

Experimental evaluation of the **Revised v3** architecture. Plan, gaps and roadmap: `docs/V3_AUDIT.md`.

Status: v3 Phases 1–7 implemented and verified live (`docs/PROGRESS.md`).
- All experiments are complete: A and B (5 seeds each), E/F, and the live C/D, G and H. Results are in
  `docs/D4_EVALUATION.md`.
- Live runs affected by service failures were discarded and repeated after the fixes (`docs/D4_EVALUATION.md` §L).
  The superseded raw files are not in `results/raw/`.
- `exp_c` also samples `docker stats` into `results/raw/exp_c/docker-stats.jsonl` (Experiment D resources).
- Results are written only by the scripts below. The results in `experiments/results/` are from the D3
  implementation and the v3 model training runs.

Live-run checks (`run_live.sh`):
- before each part, the gateway must answer `/readyz`;
- the gateway and PDP start times are logged before and after each part (a change means the part must be rerun);
- `exp_c` writes a run as `…-INVALID.json` when more than 1 % of its requests failed, and `figures.py` skips it.

| Script | Experiment | Where it runs | Raw output |
|---|---|---|---|
| `exp_a.py` | A individual detection (+ F: TCN ablation) | host, `.venv-gpu` | `results/raw/exp_a/` |
| `exp_b.py` | B collusion | host, `.venv-gpu` | `results/raw/exp_b/` |
| `exp_e.py` | E compute budget, F path ablation | host, `.venv-gpu` | `results/raw/exp_e/` |
| `exp_c.py` | C latency, D throughput | tools container (`run_live.sh c`) | `results/raw/exp_c/` |
| `exp_g.py` | G enforcement | tools container (`run_live.sh g`) | `results/raw/exp_g/` |
| `exp_h.py` | H failure modes | tools container + host faults (`run_live.sh h`) | `results/raw/exp_h/` |
| `figures.py` | all figures and tables | host, `.venv` | `results/figures/`, `results/tables/` |

Pipeline checks run with `--quick` / `--epochs 1` were kept out of `results/raw/` and are never reported.

Rules for everything in this folder:
- every figure and table is generated by a script from files in `results/raw/`; no value is typed by hand;
- every run stores `env_info.collect()` output, the git commit, seeds, parameters, and start and finish times;
- published numbers from other papers are kept apart, labelled "Reported by Reference Paper", with a page
  citation (`references/REFERENCES.md`);
- anything not measured is written as Not Reported, Not Comparable or Not Reproduced.
